# Backend Study — Project Board

스터디 기간 동안 프론트 개발자들이 **백엔드 개발에 입문**할 수 있도록 진행 중인 스터디의 첫 번째 프로젝트입니다.

기본적인 게시판 서비스를 함께 설계·구현하면서  
**Java + Spring Boot 기반 백엔드 개발 실습**과 **AWS 배포**까지 점진적으로 확장하는 것을 목표로 합니다.

---

## 🚀 프로젝트 개요

프론트 개발자분들이 백엔드 개념과 구조를 자연스럽게 이해할 수 있도록  
간단한 게시판 서비스를 함께 만들며 기능을 확장해 나가는 스터디입니다.

---

## 📌 주요 기술 스택

- **언어**: Java 21  
- **프레임워크**: Spring Boot  
- **빌드 도구**: Gradle  
- **DB**: AWS RDS (운영 환경 이전 중)  
- **배포**: AWS EC2 (운영 환경 연결 중)  
- **인증/인가**: Spring Security (JWT)

---

## 🧠 프로젝트 목표

- 여러 사용자가 이용 가능한 게시판 서비스
- 사용자 **회원가입 / 로그인**
- **CRUD** 기반 게시글 생성, 조회, 수정, 삭제
- 로컬 개발 환경 → **AWS 운영 환경 배포**  
  (EC2, RDS 연결 및 설정 경험)

---

## 📂 기능 목록

### ✔️ 사용자

- 회원가입
- 로그인 
- 패스워드 암호화
- 인증 / 인가 (JWT)

### ✔️ 게시판

- 게시글 목록 조회
- 게시글 상세 조회
- 게시글 생성
- 게시글 수정
- 게시글 삭제
- 작성자만 수정 / 삭제 가능

### ⛏️ 예정 기능 (필요 시 추가)

- 사용자 정보 조회 (간단 프로필)
- 댓글 기능
- 좋아요 / 조회수
- 이미지 업로드
- 페이징 & 검색
- OAuth 로그인 (Google / GitHub)
